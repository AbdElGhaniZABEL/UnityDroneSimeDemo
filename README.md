# Supplementary Material: A Real-Time Unity Framework for Integrated High- and Low-Level Drone Control: Standoff Object Tracking strategy as a Use Case

## Overview

This repository contains the raw flight log data and simulation parameters generated to evaluate the multirotor high-level and low-level control algorithms presented in our paper. The data was generated natively using our Unity simulation framework.

## Live WebGL Simulation Demo

To ensure full reproducibility, an interactive WebGL build of the framework is publicly available. Reviewers and researchers can use this build to run the simulation directly in their browsers, adjust parameters at runtime, and reproduce the test scenarios described in the paper.
**Access the live demo here:** [Unity Drone Sim Demo](https://abdelghanizabel.github.io/UnityDroneSimeDemo/)

## File Structure & Naming Convention

All raw data files are located in the `Dataset/` directory.  The dataset is organized into four main testing categories within the `Dataset/` folder:

* **`Dataset/1_Step_Responses`**: Evaluates the low-level controller's ability to achieve commanded setpoints (Linear and Angular axes).

* **`Dataset/2_Trajectory_Tracking`**: Evaluates continuous path following (Square, Circle, Infinity).

* **`Dataset/3_Robustness_and_Disturbances`**: Evaluates controller stability against external disturbances (Force, Torque) and parameter variations (Mass, Inertia) on the 40s Infinity trajectory.

* **`Dataset/4_Object_Tracking`**: Compares two visual tracking approaches (Dead-Zone vs. Fixed-Radius) during dynamic flight.

## Data Dictionary (CSV Headers)

Each flight log `.csv` file contains the following telemetry data, recorded at the fixed-step simulation frequency:

* **Simulation Performance:** `index`, `Time`, `StepTime`, `RealtimeFactor`, `FPS`, `CPUUsage`, `MemoryUsage`, `GPUUsage`

* **Drone State (World/Local):** `PosX, PosY, PosZ` (Position), `RotQX, RotQY, RotQZ, RotQW` (Quaternion Orientation), `RotRoll, RotYaw, RotPitch` (Euler Angles), `Vel*`, `AngVel*`

* **Desired State (Reference):** `DesPosX ... DesAngVelZ` (The target state generated by the high-level module)

* **Tracking Error:** `ErrPosX ... ErrAngVelZ` (Calculated difference between desired and current state)

* **Control Effort:** `U1, U2, U3, U4` (Total Thrust, Roll Torque, Pitch Torque, Yaw Torque)

* **Rotor Dynamics (1-4):** `W1..W4` (Angular velocities), `F1..F4` (Thrust forces), `T1..T4` (Reaction/Drag torques)

* **Target World Position:** `Tx, Ty, Tz` (The 3D position of the tracking target in world space)

* **Target Camera/Screen Space:** `Screenx, Screeny, Screenz` (Target position in screen space pixels), `Viewx, Viewy, Viewz` (Target position in viewport space, normalized 0-1)

* **Disturbances:** `FewX, FewY, FewZ` (Applied external forces, World Space), `TelX, TelY, TelZ` (Applied external torques, Local Space)

## Usage Instructions

To import and analyze this data in MATLAB, you can use the custom `drone_csv_importer` function.

**Function Signature:**

```
function drone_csv_importer(csvFile, outVar, stepSize)
    % INPUT PARAMETERS:
    %   csvFile  - String/Char. The relative or absolute path to the CSV deliverable.
    %   outVar   - String/Char. Target workspace variable name for the output table.
    %   stepSize - Integer. Downsampling interval to optimize memory bandwidth.
```

**Step-by-Step Import Example:**

1. Place the `drone_csv_importer.m` function in your MATLAB working directory.

2. Call the function, providing the relative path to the CSV file within the `Dataset/` directory, the desired workspace variable name, and the step size (use `1` to keep all data points).

3. Example: To load the 40-second Infinity trajectory test:

```
drone_csv_importer("Dataset/2_Trajectory_Tracking/TrajInf40.csv", "infP40L5", 1);
```
